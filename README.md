# Jelly Arena Remix

A vibrant gaming single-page website for **Jelly Arena** inspired by **Jack & Jelly** fruit drinks.

- Live Game Reference: https://jellyarena.digifox.live/
- Built with React 19, TanStack Start & Router, Tailwind CSS.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
